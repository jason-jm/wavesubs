Wave Subs 隐私政策

更新于 2026 年 11 月 15 日

概述

Wave Subs 是一款桌面应用，无需注册。应用不收集使用统计或崩溃报告。

在本地处理的数据

导入的影片、音频、字幕，以及生成的字幕、编辑记录和任务缓存都保存在你的设备上。语音识别、时间对齐、画面文字识别和本地翻译在本机运行。模型下载完成后，你可以离线制作和导出字幕。

应用何时联网

下载模型。当你选择下载模型时，应用会访问 Hugging Face、hf-mirror.com 或 ModelScope。下载源可看到请求的模型文件和 IP 地址。

云端翻译。如果你配置并选择第三方服务，应用会把需要翻译的字幕文本、启用画面文字翻译时识别出的文字，以及匹配的术语表条目发给该服务商。影片、音频和视频帧保留在设备上。API 密钥用于向所选服务商认证。系统加密可用时，应用会加密存储密钥。不可用时，密钥会以可还原的 Base64 编码保存在本地设置中。

检查更新。官网发行版默认在每次启动后向 GitHub 请求一次 版本清单，在本机比较版本。GitHub 可以看到请求的 IP 地址。检查不包含影片、字幕或 API 密钥。你可以在设置中关闭「启动时检查更新」，也可以手动检查。

第三方组件

随包提供的 ffmpeg、whisper.cpp 和 llama.cpp 在本地运行。详情见第三方组件许可。

官网反馈表单

点击「在 GitHub 预览」时，网站会将你填写的内容作为草稿交给 GitHub。从应用打开表单时，还会附上应用版本、系统和界面语言。你可以在 GitHub 上修改或放弃草稿。登录并确认提交后，反馈将出现在公开的 GitHub Issues，他人可以阅读和回复。表单不要求邮箱，请勿在反馈中填写个人资料。GitHub 会依其隐私声明处理这些请求。

儿童隐私

本应用面向一般用户，不专为儿童设计。

政策变更

如本政策有实质性变更，我们会在本页面更新并注明日期。
